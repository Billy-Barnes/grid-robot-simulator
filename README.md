# Grid Robot Simulator

## Overview: 
A Python program that simulates a robot navigating around a 2D grid, with interactive movement, obstacle detection and boundary validation.

## Current Functionality:

- 2D robot positioning.
- Horizontal and vertical movement.
- User-controlled movement using W, A, S and D.
- Grid boundary validation.
- Input validation.
- Obstacle detection and collision prevention.
- Destination detection.
- Movement testing using assertions.
- m × n grid visualisation.
- Robot displayed at its current coordinates.
- Obstacles and destination displayed on the grid.
- Grid automatically replots after successful movement.
- Invalid boundary and obstacle movements are rejected.

## Technologies:
Python.
